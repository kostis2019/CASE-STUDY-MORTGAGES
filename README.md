# Credit Risk Case Study – Mortgages

A credit risk modelling case study using a mortgage portfolio dataset.

## Contents

- `Case-Study-Mortgages.ipynb` — complete case study, including data exploration, PD modelling, model evaluation and credit policy analysis.

## Methodology

The analysis covers:

- Portfolio and data overview
- Structural vs. behavioural risk modelling
- Probability of Default (PD) modelling
- Model performance evaluation
- Credit policy analysis
- Expected Loss and Economic Capital assessment

## Tools

Python, pandas, scikit-learn, XGBoost, matplotlib and seaborn.
